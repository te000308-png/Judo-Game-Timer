柔道試合タイマー（JT-801 相当）操作メモ

画面

・横向き・縦向きのどちらでも操作できます。横向きは「試合時間／ポイント／抑え込み」の3列、縦向きはポイント部が上段、試合時間部・抑え込み時間部が下段になります。
・「表示モード」ボタンで 自動 → モバイル → タブレット を切り替えます（自動は画面サイズで判定。選んだモードは次回も保持されます）。
・画面に収まらないときは下にスクロールしてポイント部などを操作できます。スクロールしても表示盤は画面上部に固定されるので、時計を見ながら操作できます。

ブザー

・試合開始・「待て」からの再開ではブザーは鳴りません。
・試合時間終了：2.5秒／抑え込み時間経過（一本）：2.5秒。
・「ブザー」ボタンは押している間だけ鳴ります。
・「音切替」で 大・連続 → 大・断続 → 消音 → 小・連続 → 小・断続 の5パターン。

試合時間部

・START/STOP：試合時間の開始／停止（＝「待て」）。停止中に分・秒 ±で時間訂正。
・横画面では、表示盤の時計の数字をタップしても開始／停止できます。（縦画面では誤操作防止のため無効）
・GS：ゴールデンスコアへ。0からカウントアップ（上限＝P2）。もう一度押すと解除。

抑え込み時間部

・START/STOP：抑え込み開始／停止。RESET&START：0に戻してすぐ再スタート。
・抑え込みリセット：抑え込み解除（表示盤の「抑」消灯・得点確定）。
・◀ ▶：抑え込み側の選手（カラーが点滅）。抑え込みを開始してから選べます。一本になって試合が終わった後に選んでも、その時の秒数からポイントと勝者がさかのぼって付きます。もう一度押すと解除、反対側を押すと付け替えになります。
・自動ポイント（連動）：P5秒→有効、P4秒→技あり、P3秒→一本。
　技ありを持っている選手はP4秒で合わせ技一本。
・停止中に秒 ±で抑え込み時間を訂正すると、連動時はポイントも自動で訂正されます。
・ゴールデンスコア中の抑え込みは、P3・P4・P5のうち最も短い時間で試合終了。

試合時間終了と抑え込み

・抑え込み継続中に試合時間が0になった場合、ブザーは鳴らず、表示は設定試合時間から総試合時間をカウントアップ。抑え込み一本、または抑え込み解除で試合終了（ブザー）。
・試合終了後5秒以内に抑え込みSTARTを押すと、試合終了と同時に抑え込みが始まったものとして再開します。

リセット系

・ゲームリセット：得点をクリアして次の試合表示へ（設定値と選手カラーは残ります）。
・オールクリア：得点・指導・負傷・抑え込み・勝者・選手カラーをすべて消去（P1〜P5の設定値は残ります）。
・オールリセット：設定値も含めて工場出荷時の初期設定に戻します。
・オールクリアとオールリセットは誤操作防止のため2回押しです。1回押すと「もう一度押す」に変わり、5秒放置すると取り消されます。

ポイント部

・一本 I（0～1）／技あり W（0～2）／有効 Y（0～9）／指導 S1・S2／反則 S3／負傷（0～2）。
・訂正を押してからポイントボタンを押すと −1 されます。
・反則(S3)：相手に自動的に一本、抑え込み表示部に「H」。
・WIN：勝者側に金色でWINNERを表示し、カラーとポイントが点滅します。一本・反則・抑え込み一本のときは自動で勝者が決まります（WINボタンで手動変更も可能）。
・選手カラー：OFF:OFF → 白:赤 → 赤:白 → 青:白 → 白:青 → OFF:OFF。

設定（SETTING）

・「設定」を押すたびに P1 試合時間 → P2 GS時間 → P3 抑え込み1(I) → P4 抑え込み2(W) → P5 抑え込み3(Y) → 終了。
・P1/P2 は試合時間部の 分・秒 ±、P3～P5 は 秒 ± で変更します。
・初期値：P1 4分／P2 99分59秒／P3 20秒／P4 10秒／P5 5秒。柔道1＝連動、柔道2＝非連動。
